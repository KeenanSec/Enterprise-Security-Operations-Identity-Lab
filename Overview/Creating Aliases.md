## Creating Firewall Aliases

Aliases group IPs so firewall rules reference a name instead of a hardcoded address. When an IP changes, I update the alias once instead of editing every rule.

1. Go to `Firewall` > `Aliases`, then press the orange `+`.

This first alias stores all the service IPs.
